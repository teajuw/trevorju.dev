## Thesis

Demand outran hiring, so the sales org was rebuilt in January 2026 without
buying new tools. The agent became the layer that connects the tools already in
use, and the effort went into the gaps between systems, where context is lost.

## The four investments

1. **Self-serve funnel.** Every inbound lead is enriched, qualified and routed by
   agents; the router decides whether a person gets the lead at all. 54% of new
   enterprise logos in 2026 came through self-serve.
2. **The agent as connective tissue.** It drafts proposals from deal context,
   checks them against policy and starts the contract workflow. It runs most of
   the forecast; managers review and talk only about deviations. It updates the
   CRM; the rep reviews and approves.
3. **One front door for support functions.** A single Slack intake for deal desk,
   legal, security and compliance. The agent triages: if precedent and policy
   cover the request it resolves it there; otherwise it attaches the context,
   assigns a person and tells the requester. Requests are increasingly filed by
   an agent rather than the rep.
4. **Top performers' workflows encoded as skills.** New reps get a territory and
   a plugin that bundles the skills, in place of a six-week ramp. Five skills
   every rep runs daily: morning briefing, call prep, customer follow-up,
   competitive intel, create an asset. Anything not followed up resurfaces in the
   next morning's briefing.
