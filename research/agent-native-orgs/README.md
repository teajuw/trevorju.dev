about this portfolio, a deployed site that sessions in other repos post to?

## How far to trust it

- Sources 01 to 05 were read in full from the live page.
- Source 06 is second-hand: the video's transcript could not be fetched, so the
  note is built from the event host's write-ups.
- Source 07 was gathered by a subagent. Its quotes were extracted by a fetch
  tool and should be spot-checked before being published anywhere. Three of its
  sources were read through a mirror, a README or secondary coverage.
- Nearly every source is a company describing its own practice. Only two
  measured anything against a baseline: the AI organizations study (02) and
  Vercel's skills evaluation (07, item 9).
